Version 0.1.0 · VSIX release · free

01

Install the VSIX

Download the .vsix from the release page. In VS Code or Cursor, open Extensions, open the menu, then choose Install from VSIX....

02

Stage a selection

Highlight code, run Boottray: Stage Selection, and review the proposed change in the Boottray panel before anything is written.

03

Apply when ready

Keep edits nearby until you are sure. Apply what you want, discard the rest. Updates land on GitHub as new releases.
