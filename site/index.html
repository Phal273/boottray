boottray v0.1.0

Wipe your feet.

I got tired of cleaning up edits I never approved. Silent inserts make a mess. Boottray is a small extension for VS Code and Cursor that gives a selection a place to land first.

Stage a range with Boottray: Stage Selection. The hunk sits in a side-panel tray. Accept applies a WorkspaceEdit. Reject throws it out. The file does not change until you pick.

Download the VSIX free · the VSIX is the install

Highlight some text, or don’t — no selection stages the whole file. Open the Boottray icon in the activity bar, expand the card, read the hunk. That is the whole product.

To put it on a machine, grab boottray-0.1.0.vsix from the v0.1.0 release. In VS Code or Cursor: Extensions → ⋯ → Install from VSIX… Pick the file. Command Palette after that. There is no marketplace listing and no account, because there is no service.
