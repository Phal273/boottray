Wipe your feet.

Boottray is a small extension for VS Code and Cursor. You stage an editor selection into a review tray, inspect the hunk, then Accept or Reject. Accept applies a WorkspaceEdit. Reject throws it out. The file does not change until you pick.

Download the VSIX v0.1.0 · free · not on the marketplace

How it actually works

Highlight some text — or don’t, and it stages the whole file. Run Boottray: Stage Selection from the Command Palette. Open the Boottray icon in the activity bar. Expand the card, read the hunk.

Accept writes. Reject doesn’t. Either way, nothing slips into the document on its own. Think of it as a mudroom: leave the boots on the tray before they track through the house.

Install the VSIX

  1. Grab boottray-0.1.0.vsix from the v0.1.0 release.
  2. In VS Code or Cursor, open the Extensions view.
  3. Open the ⋯ menu and choose Install from VSIX…
  4. Pick the file. Then Command Palette → Boottray: Stage Selection.

That’s the whole path. No account, because there is no service.
