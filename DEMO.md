# Boottray walkthrough

A quick click path for a real selection.

1. Open any file with text.
2. Select a few lines in the editor.
3. Open the Command Palette with `Ctrl+Shift+P` or `Cmd+Shift+P`.
4. Run `Boottray: Stage Selection`.
5. Click the Boottray icon in the activity bar, then expand the staged card.
6. Inspect the selection. The editor has not changed.
7. Click `Accept` to apply the selection, or `Reject` to discard it.

The punchline: stage first, touch files second.
